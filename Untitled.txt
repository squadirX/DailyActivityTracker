# 1. মূল উদ্দেশ্য

আমাদের লক্ষ্য Windows কম্পিউটারের D: Drive-কে PNDCC, SIEM, WCCM এবং Smart Backup-সংক্রান্ত প্রয়োজনীয় logs, databases, reports ও archives-এর কেন্দ্রীয় storage হিসেবে প্রস্তুত করা।

- Windows computer = Central Storage / Server
- MacBook = Command Center
- Windows D: Drive = সম্ভাব্য central data location

Mac-এর internal storage প্রায় পূর্ণ। তাই যাচাইয়ের পর প্রয়োজনীয় operational data কেন্দ্রীয় storage-এ রাখার ব্যবস্থা করতে হবে।

**কাজের নিয়ম:**
1. আগে যাচাই।
2. তারপর পরিকল্পনা।
3. তারপর অনুমোদিত copy।
4. এরপর file count ও SHA-256 দিয়ে verification।
5. সব যাচাই সফল না হওয়া পর্যন্ত original files অক্ষত থাকবে।
6. কোনো service, database, configuration বা file অনুমতি ছাড়া পরিবর্তন করা যাবে না।

# 8. আগামীকাল প্রথম কাজ: D: Drive পরীক্ষা

প্রথমে শুধু read-only command চালাতে হবে।

এটি:
- D: Drive mounted আছে কি না দেখবে।
- Storage capacity দেখাবে।
- Top-level folders দেখাবে।
- Top-level files দেখাবে।
- Read/write permission পরীক্ষা করবে।
- কোনো file তৈরি বা পরিবর্তন করবে না।

```bash
bash <<'BASH'
ROOT="/Volumes/Windows_D_ADATA"

echo "========== WINDOWS D DRIVE: READ-ONLY CHECK =========="

if [ ! -d "$ROOT" ]; then
  echo "ERROR: D: Drive is not mounted at $ROOT"
  exit 1
fi

echo ""
echo "=== STORAGE CAPACITY ==="
df -h "$ROOT"

echo ""
echo "=== TOP-LEVEL FOLDERS ==="
find "$ROOT" -mindepth 1 -maxdepth 1 -type d -print 2>/dev/null | sort

echo ""
echo "=== TOP-LEVEL FILES ==="
find "$ROOT" -mindepth 1 -maxdepth 1 -type f -print 2>/dev/null | sort

echo ""
echo "=== ACCESS PERMISSIONS ==="
if [ -r "$ROOT" ]; then echo "Read access: YES"; else echo "Read access: NO"; fi
if [ -w "$ROOT" ]; then echo "Write permission reported by macOS: YES"; else echo "Write permission reported by macOS: NO"; fi

echo ""
echo "========== CHECK COMPLETE =========="
BASH
```

Output পাওয়ার পর folder structure দেখে পরবর্তী ধাপ ঠিক করতে হবে।

**এই ধাপে কোনো folder তৈরি করা হবে না।**
