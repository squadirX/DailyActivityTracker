What will you find in Recent Activity?

Recent Activity displays real diagnostic events and their timestamps.

  • Wi-Fi and Ethernet connectivity changes
  • Network failover and recovery events
  • FTP/FTPS and SMB connection or test results
  • Storage detection and authorized file transaction results
  • Event time, result and diagnostic status

Status meaning: Green means confirmed positive, Red means confirmed failure, and blinking Yellow means pending or not yet verified.

Important: Live Refresh shows the latest diagnostic update. It does not mean a historical event has been recorded. Only actual events should appear here; no synthetic events or unverified successes are claimed.
